Sistema Ijuí para Windows e Android

Os sistemas da Prefeitura num aplicativo só. Você entra uma vez, com o usuário que o administrador cadastrou, e vê só os módulos liberados para você — no computador e no celular.

Baixar para Windows
Windows 10 ou 11 · 64 bits · não precisa ser administrador
📱 Baixar para Android
Android 7 ou mais novo · baixe e instale no próprio celular
1

Instale

Abra o arquivo baixado. A instalação é automática e cria o atalho Sistema Ijuí na Área de Trabalho e no Menu Iniciar.

2

Entre uma vez

Digite o usuário e a senha que o administrador passou. Nas próximas vezes o app já abre direto, sem pedir de novo.

3

Pronto

Os módulos liberados aparecem na barra da esquerda. O app se atualiza sozinho: não precisa baixar de novo quando sair versão nova.

🛡️

Se o Windows mostrar “O Windows protegeu o computador”

Clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o aplicativo ainda não tem uma assinatura digital comprada — não quer dizer que haja algo errado com ele.

Não tem usuário? Peça ao administrador do sistema. Esqueceu a senha? Também é com ele.

📱

No celular Android

  1. Toque em Baixar para Android no próprio celular e abra o arquivo Sistema-Ijui.apk.
  2. Se aparecer “Por segurança, não é permitido instalar apps desta fonte”, toque em Configurações, ligue Permitir desta fonte e volte.
  3. Toque em Instalar. O ícone Sistema Ijuí aparece na tela inicial.
  4. Entre com o mesmo usuário e senha do computador. Quem entra com a conta Google: no computador, no menu da conta, use Criar senha para o celular.

O app se atualiza sozinho: as telas vêm do sistema. Quando sair uma versão nova do aplicativo, ele mesmo avisa.
